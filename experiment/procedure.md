## Introduction to Interactive Simulation:

* This experiment introduces hierarchical transformations in 3D space, demonstrating their effects on four different shapes: Cube, Tetrahedron, Dodecahedron, and Octahedron. Each shape undergoes a series of animated transformations along all three axes (X, Y, and Z).

## Step-by-Step Procedure:

### 1. Initial Setup and Navigation
1. When you start the simulation, you'll see the four shapes in their initial positions
2. Use the mouse controls to navigate the 3D space:
   - Left-click and drag to translate (move) the view
   - Right-click and drag to rotate the view
   - Scroll wheel to zoom in/out
3. Enable the grid planes (XY, YZ, XZ) to better understand the 3D coordinate system

### 2. Understanding the Controls
1. **Display Settings** (Left Panel):
   - Lock Graph: Prevents accidental movement of the view
   - Lock Zoom: Disables zoom functionality
   - Lock Rotate: Disables rotation of the view
   - Grid Options: Toggle different grid planes to visualize the 3D space

2. **Shape Controls** (Left Panel):
   - Add: Create new shapes at specified coordinates
   - Select: Highlight a shape for transformation
   - Edit: Modify shape properties
   - Delete: Remove shapes from the scene

### 3. Performing Transformations

#### A. Translation
1. Select a shape using the "Select" button
2. Set translation values:
   - Use the sliders to set desired X, Y, Z values
   - OR input specific values in the translation vector fields
3. Click "Apply Translation" to move the shape
4. Observe how the shape moves in 3D space
5. The transformation matrix will update to show the current transformation

#### B. Scaling
1. Select a shape using the "Select" button
2. Set scaling factors:
   - Use the sliders to set desired X, Y, Z scaling values
   - OR input specific values in the scaling controls
3. Click "Apply Scaling" to resize the shape
4. Observe how the shape scales along each axis
5. The transformation matrix will update to show the current transformation

#### C. Rotation
1. Select a shape using the "Select" button
2. Choose rotation axis (X, Y, or Z) from the dropdown
3. Set the rotation angle (θ) in degrees
4. Click "Change Axis" to apply the rotation
5. Observe how the shape rotates around the selected axis
6. The transformation matrix will update to show the current transformation

### 4. Observing Results
1. **Transformation Matrix** (Right Panel):
   - Watch how the matrix updates with each transformation
   - The matrix shows the cumulative effect of all transformations
   - Each row represents a transformation component

2. **Visual Feedback**:
   - Observe how shapes move, rotate, and scale in 3D space
   - Use different grid planes to understand the spatial relationships
   - Compare the effects of different transformation sequences

3. **Interactive Learning**:
   - Try different combinations of transformations
   - Observe how the order of transformations affects the final result
   - Use the "Reset All" button to start over

### 5. Tips for Better Understanding
1. Start with simple transformations (single axis) before trying complex combinations
2. Use the grid planes to understand the spatial relationships
3. Pay attention to the transformation matrix to understand the mathematical representation
4. Try to predict the result before applying transformations
5. Use the "Reset All" button if you want to start fresh

### 6. Common Observations
1. Translation moves shapes without changing their size or orientation
2. Scaling changes the size of shapes along each axis independently
3. Rotation changes the orientation of shapes around the selected axis
4. The order of transformations matters - try different sequences to see the difference
5. The transformation matrix shows how each transformation affects the coordinate system

## Note:
- Make sure the slider is at zero before making any changes for accurate adjustments
- The simulation is optimized for desktop screens, though basic functionality is available on mobile devices
- You can always use the "Reset All" button to return to the initial state
